- *Type:* No-Code Website Builder

## ✅ Features Implemented
- 🏠 *Homepage* — Store name, welcome message, featured products
- 🛍️ *Product Page* — 5+ food & drinks products with images, prices, descriptions
- ℹ️ *About Page* — Store background and mission statement
- 📞 *Contact Page* — Email, phone, and contact form
- 🛒 *Cart Functionality* — Add to cart buttons on product pages
